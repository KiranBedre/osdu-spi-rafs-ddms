# Relative Permeability Data Schema v1.0.0 -> v1.1.0

## Overview
Schema updated from v1.0.0 to v1.1.0.

## Changes

### New Fields
- `InitialConditions.RelativePermeability.FluidTypeID` — the fluid type for which the initial relative permeability is reported; uses `CoreAnalysisFluidType` reference data
- `TerminalConditions.RelativePermeability.FluidTypeID` — the fluid type for which the terminal relative permeability is reported; uses `CoreAnalysisFluidType` reference data
- `PermeabilityTestSteps[*].RelativePermeability[*].FluidTypeID` — the fluid type for which the per-step relative permeability is reported; uses `CoreAnalysisFluidType` reference data

### Corrections
- `RelativePermeabilityCrossover` — UOM annotation corrected from `UOM:dimensionless` to `UOM:permeability rock`
- `InitialConditions.EffectivePermeability.FluidTypeID` — pattern updated from `SampleInjectionFluidType` to `CoreAnalysisFluidType`
- `InitialConditions.Saturation.FluidTypeID` — pattern updated from `SampleInjectionFluidType` to `CoreAnalysisFluidType`
- `TerminalConditions.EffectivePermeability.FluidTypeID` — pattern updated from `SampleInjectionFluidType` to `CoreAnalysisFluidType`
- `TerminalConditions.Saturation.FluidTypeID` — pattern updated from `SampleInjectionFluidType` to `CoreAnalysisFluidType`
- `PermeabilityTestSteps[*].InjectionRate[*].FluidTypeID` — pattern updated from `SampleInjectionFluidType` to `CoreAnalysisFluidType`
- `PermeabilityTestSteps[*].CumulativeProduction.FluidTypeID` — pattern updated from `DisplacedFluidType` to `CoreAnalysisFluidType`
- `PermeabilityTestSteps[*].EffectivePermeability[*].FluidTypeID` — pattern updated from `SampleInjectionFluidType` to `CoreAnalysisFluidType`
- `PermeabilityTestSteps[*].Saturation.FluidTypeID` — pattern updated from `SampleInjectionFluidType` to `CoreAnalysisFluidType`
- `PermeabilityTestSteps[*].ProductionProfiles[*].FluidTypeID` — pattern updated from `DisplacedFluidType` to `CoreAnalysisFluidType`
- `OilTypeID` — pattern updated from `DisplacedFluidType` to `CoreAnalysisFluidType`
- `GasTypeID` — pattern updated from `SampleInjectionFluidType` to `CoreAnalysisFluidType`
- `WaterTypeID` — pattern updated from `SampleInjectionFluidType` to `CoreAnalysisFluidType`

### Soft Deprecation
- `InitialConditions.RelativePermeability.FluidSystemAnalysisTypeID` — deprecated in favor of `FluidTypeID`
- `TerminalConditions.RelativePermeability.FluidSystemAnalysisTypeID` — deprecated in favor of `FluidTypeID`
- `PermeabilityTestSteps[*].RelativePermeability[*].FluidSystemAnalysisTypeID` — deprecated in favor of `FluidTypeID`

## Migration Notes
- All `FluidTypeID` fields that previously used `SampleInjectionFluidType` or `DisplacedFluidType` reference data must now use `CoreAnalysisFluidType`. Existing records with old patterns will fail schema validation against v1.1.0.
- `RelativePermeabilityCrossover` values previously stored as dimensionless fractions are now expected in permeability rock units (e.g. millidarcy).
- Populate the new `FluidTypeID` on `RelativePermeability` objects; `FluidSystemAnalysisTypeID` remains accepted but is deprecated.
