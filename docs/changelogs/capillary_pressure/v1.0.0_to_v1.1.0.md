# Capillary Pressure v1.0.0 -> v1.1.0

## Overview
Schema updated from v1.0.0 to v1.1.0. Two new fields were added to the `Endpoints`
sub-object in both `ForcedImbibition` and `ForcedDrainage`.

## Changes

### New Fields
- `ForcedImbibition.Endpoints.EffectivePermeabilityOfInjectionFluid` — The effective
  permeability of the injection fluid at the start of the imbibition phase
  (`UOM:permeability rock`).
- `ForcedImbibition.Endpoints.RelativePermeabilityOfInjectionFluid` — The relative
  permeability of the injection fluid at the start of the imbibition phase
  (`UOM:volume per volume`).
- `ForcedDrainage.Endpoints.EffectivePermeabilityOfInjectionFluid` — The effective
  permeability of the injection fluid at the start of the drainage phase
  (`UOM:permeability rock`).
- `ForcedDrainage.Endpoints.RelativePermeabilityOfInjectionFluid` — The relative
  permeability of the injection fluid at the start of the drainage phase
  (`UOM:volume per volume`).

## Migration Notes
- All new fields are optional; existing v1.0.0 records remain valid.
- The new fields complement the existing `EffectivePermeabilityOfResidualFluid` and
  `RelativePermeabilityOfResidualFluid` fields, which describe the residual (end-state)
  fluid. The new fields describe the injection (start-state) fluid.
