# Wettability Index Data Schema v1.0.0 -> v2.0.0

## Overview
Schema updated from v1.0.0 to v2.0.0.

## Changes

### New Fields
- `TestSteps`
- `TestSteps[*].SequenceNumber`
- `TestSteps[*].CapillaryPressureAnalysisID`
- `TestSteps[*].SaturationProcessMethodID`
- `TestSteps[*].InjectionFluidID`
- `TestSteps[*].DisplacedFluidID`
- `TestSteps[*].EndPoints`
- `TestSteps[*].EndPoints.CapillaryPressureMax`
- `TestSteps[*].EndPoints.EndfaceSaturationAtCapillaryPressureMax`
- `TestSteps[*].EndPoints.AveragePhaseSaturationAtCapillaryPressureMax`
- `TestSteps[*].EndPoints.CapillaryPressureMin`
- `TestSteps[*].EndPoints.EndfaceSaturationAtCapillaryPressureMin`
- `TestSteps[*].EndPoints.AveragePhaseSaturationAtCapillaryPressureMin`
- `TestSteps[*].TotalProducedVolume`

### Modified Fields
- `Temperature` - moved from `WettabilityIndexData.Temperature` to the root
- `WettabilityIndex` - moved from `WettabilityIndexData.WettabilityIndex` to the root
- `ConfiningPressure` - moved from `WettabilityIndexData.ConfiningPressure` to the root
- `DesaturationMethod` - moved from `WettabilityIndexData.DesaturationMethod` to the root
- `FluidSystem` - moved from `WettabilityIndexData.FluidSystem` to the root
- `InitialWaterSaturation` - moved from `WettabilityIndexData.InitialWaterSaturation` to the root
- `Remarks` - moved from `WettabilityIndexData.Remarks` to the root

### Deprecated/Removed Fields
- `WettabilityIndexData`
- `WettabilityIndexData.CapillaryPressureAnalysisID`
- `WettabilityIndexData.ForcedImbibedBrineVolume`
- `WettabilityIndexData.ForcedImbibedOilVolume`

- `WettabilityIndexData.InitialOilSaturation`
- `WettabilityIndexData.SpontaneousImbibedBrineVolume`
- `WettabilityIndexData.DisplacedOilVolume`
- `WettabilityIndexData.BrineImbibitionBrineSaturation`
- `WettabilityIndexData.BrineDisplacementOilSaturation`
- `WettabilityIndexData.SpontaneousImbibedOilVolume`
- `WettabilityIndexData.OilImbibitionBrineSaturation`
- `WettabilityIndexData.DisplacedBrineVolume`
- `WettabilityIndexData.DisplacementRatio`
- `WettabilityIndexData.OilImbibitionOilSaturation`
- `WettabilityIndexData.InjectionFluidID`
- `WettabilityIndexData.DisplacedFluidID`
- `WettabilityIndexData.InitialCapillaryPressure`
- `WettabilityIndexData.ForcedWaterImbibition`
- `WettabilityIndexData.ForcedOilImbibition`

## Migration Notes
- Existing v1.0.0 records remain valid and readable via content_schema_version=1.0.0. 
- InjectionFluidID and DisplacedFluidID fields that previously used SampleInjectionFluidType/DisplacedFluidType reference data must now use CoreAnalysisFluidType. New records with old patterns will fail schema validation against v2.0.0.
